# Personal Portfolio — [sepehr.uk](https://sepehr.uk)

Built with React, deployed on Netlify.

## Stack

- React.js, React Router, React Bootstrap
- react-vertical-timeline-component, typewriter-effect, react-tsparticles

## Development

```bash
npm install
npm start        # http://localhost:3000
npm run build
```

## Pages

- `/` — Home
- `/about` — Background and skills
- `/experience` — Work history and education
- `/project` — Projects
- `/resume` — Resume
- `/contact` — Contact form
